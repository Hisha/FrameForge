# Test fixtures

Immutable copies of real files that FrameForge must handle correctly. They are committed so the
test suite never depends on a sibling repository being present on the machine running it.

## NativeHuntsFrame.xml

    Source:   mod-native-hunts (content/client/Interface/FrameXML/NativeHuntsFrame.xml)
    Upstream: https://github.com/ <the mod-native-hunts repository>
    License:  MIT, the same license as FrameForge; see /LICENSE
    SHA-256:  42673d3fc3f2046315de8cb1cb630ad018769734cf383e5c5b0bdb9eafda47c0

Byte-for-byte copy of the real World of Warcraft 3.3.5a FrameXML document shipped by the
Native Hunts module. It is the primary development fixture for the FrameXML importer.

Do not edit this file. It is the thing under test, and editing it to make an import "work" would
defeat the point of having a real fixture. `FrameXmlImportTests` asserts this exact digest so an
accidental edit fails loudly.

The companion Lua file (`NativeHuntsFrame.lua`) is deliberately NOT copied: FrameForge never
executes Lua, and importing must not depend on it. The importer reports the script instead.

Known external dependencies of this document, which is why the importer emits placeholder
diagnostics for it: it attaches to Blizzard's `LFDParentFrame` and its tab buttons inherit
`CharacterFrameTabButtonTemplate`. Neither is defined in this file; both come from the stock
client at runtime. `mod-native-hunts/docs/CLIENT_UI.md` records the 355x500 parent size the
module's Lua applies, which is the same size FrameForge's external-frame placeholder defaults to.
